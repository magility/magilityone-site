# magilityone-site

De marketingsite van MagilityOne (https://magilityone.com), de weekplanner voor wat echt belangrijk is.

Statische HTML, geen buildstap. Hostinger deployt deze repository automatisch naar public_html van magilityone.com.

## Werkwijze

- Wijzigingen gaan via een commit op main (of een pull request die Mark merget).
- Na elke push haalt Hostinger de wijzigingen binnen en staat de site live.
- Publiceren gebeurt alleen na akkoord van Mark ter Voert.

Beheerd door Magility B.V. Onderhouden samen met Claude, de vaste SEO/GEO-specialist van MagilityOne.
